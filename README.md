# 不确定性感知知识蒸馏算法框架
Uncertainty-Aware Knowledge Distillation

## 📖 项目概述
传统知识蒸馏多采用统一的知识迁移方式，难以区分样本特征差异，在未知类别、开放场景下泛化能力不足。本项目将**不确定性估计与知识蒸馏深度融合**，通过对模型输出与特征表达进行不确定性量化，精准区分已知类别知识与新类别特征，实现自适应差异化蒸馏。通过构建分类、聚类双任务学习模型，有效提升轻量化模型的识别精度、鲁棒性与场景适配能力，适配开放集识别与智能模型优化场景。

## 🎯 核心亮点
- **不确定性量化建模**：对模型特征与预测结果进行细粒度不确定性评估，精准判别已知样本与未知样本特征差异。
- **自适应差异化蒸馏**：针对不同不确定度样本采用个性化蒸馏策略，解决传统统一蒸馏效率低、适配性差的问题。
- **双任务协同优化**：结合分类与聚类任务，同时实现已知类别精准识别和未知特征挖掘，适配开放场景需求。
- **轻量化高性能落地**：基于师生蒸馏架构压缩模型体积，在保证推理效率的同时保留高泛化能力。
