# 方法选择依据与模块说明

## 一、总体说明

本项目不是将多个算法简单拼接，而是按照开放环境下新类发现的任务链路，将模型训练、未知样本拒识和候选新类别聚类分别建模，再通过统一实验协议进行对照。各模块承担的作用不同：

- 知识蒸馏解决“如何获得稳定的学生模型表征”；
- 不确定性估计解决“模型对当前预测是否可靠”；
- 开放集拒识解决“哪些样本不属于已知类别”；
- PCA 降维与 KMeans 聚类解决“如何对筛出的候选样本进行初步组织”；
- 多指标评价解决“局部拒识改善是否真正转化为完整新类发现收益”。

因此，汇报时应明确说明：当前已经形成的是“开放集识别 + 候选聚类”的两阶段实验流程，尚不能表述为完整的新类发现问题已经解决。

## 二、开放环境任务定义与数据协议

### 1. 方法含义

开放环境下，训练阶段只能获得已知类别的标注信息；测试或实际应用阶段可能出现训练类别集合之外的新类别。模型需要同时完成已知类别分类和未知样本拒识，后续再对被筛出的未知候选进行聚类。

### 2. 为什么采用这一任务定义

如果将测试阶段的未知类别标签用于训练或阈值选择，模型就获得了本应未知的信息，实验结果会高估方法效果。因此，本项目规定：未知类别标签不参与训练、模型选择和阈值校准，只在最终评价阶段使用。

### 3. 具体设置与作用

当前主要使用 CIFAR-100，完成 60/40 已知—未知类别划分，并设置 semantic-hard 类别划分。60/40 划分用于建立统一的开放集对照条件；semantic-hard 划分重点考察语义相近类别之间的特征重叠问题。三组不同类别划分用于检验结论是否依赖某一次随机划分。

这一设计参考开放集识别中“训练类别与未知类别分离”的基本设定，同时结合新类发现任务中未知类别无标注的要求。semantic-hard 不是某篇论文中直接复制的算法，而是本项目用于放大类别相似性问题的实验控制变量。

## 三、基础分类模型与共享表征

### 1. scratch CNN：基础对照

scratch CNN 指不使用教师模型知识、直接从训练数据学习分类表征的基础模型。它的作用不是作为最终方案，而是提供一个“没有知识蒸馏时模型表现如何”的参照。

选择它的原因是：如果没有基础对照，就无法判断后续性能变化究竟来自知识蒸馏、不确定性加权，还是来自模型本身的训练差异。所有改进方法都需要在相同数据划分、训练条件和评价协议下与该基线比较。

### 2. shared-backbone：共享主干表征对照

shared-backbone 指拒识表征分支使用学生模型已经学习到的主干特征，或者以该主干进行初始化，而不是完全使用随机初始化的独立编码器。这样做的目的，是让分类任务学习到的类别语义与拒识任务共享一部分特征空间。

选择这一结构的依据是共享表征和多任务学习思想：多个相关任务共享底层特征，可以减少不同分支之间的表征分布差异。该方法不是直接照搬某一篇论文中的完整算法，而是将共享表征思想用于本项目的开放集拒识对照。

它可能产生作用的原因是：未知样本能否被拒识，很大程度上取决于特征空间中已知类别支持区域的形状。如果拒识分支完全使用另一套随机表征，它学习到的空间可能与分类模型不一致；共享主干有助于保持分类语义和拒识边界的一致性。

当前三组类别划分的结果表明，shared-backbone 将 AUROC 从 0.7675 提升至 0.7995，未知类别拒识率从 21.55% 提升至 25.16%，两个指标在三组实验中的改善方向一致。因此，目前只能得出“共享表征对拒识具有稳定的局部帮助”，不能据此认为完整新类发现已经解决。

## 四、知识蒸馏模块

### 1. standard-KD：为什么需要教师—学生结构

知识蒸馏是指让性能较强的教师模型向学生模型迁移分类知识。标准知识蒸馏通常使用教师和学生输出分布之间的温度缩放 KL 散度，使学生不仅学习硬标签，还学习教师对不同类别之间相似性的判断。

其基本形式可以表示为：

```text
L_KD = T² · KL(p_teacher^T || p_student^T)
```

其中，T 是温度参数，p_teacher^T 和 p_student^T 是温度缩放后的类别概率分布。

选择 standard-KD 的原因有两点：第一，它是知识蒸馏领域最基本、最容易复现的对照方法；第二，它可以检验普通知识迁移本身是否能够改善开放环境下的表征。如果 uncertainty-KD 没有 standard-KD 作为对照，就无法判断收益到底来自蒸馏，还是来自不确定性机制。

该部分主要参考 Hinton、Vinyals 和 Dean 提出的知识蒸馏方法（2015）。

### 2. uncertainty-KD：为什么引入不确定性权重

标准蒸馏默认教师模型对所有样本的判断都同样可靠，但在开放环境中，教师模型也可能遇到语义相近的新类别，并对未知样本产生过高置信度。如果学生无差别地模仿这些判断，可能会继承教师模型对未知样本的错误分类倾向。

因此，项目尝试根据教师模型的不确定性调整蒸馏强度。当前实现中，样本级蒸馏损失可以写成：

```text
L_unc-KD = exp(-u_teacher) · L_KD
```

其中，u_teacher 表示教师模型对该样本的不确定性。教师越确定，蒸馏权重越大；教师越不确定，蒸馏权重越小。实现中还支持对批次权重进行均值归一化，以避免改变整体蒸馏损失规模。

选择该方法的依据是“不确定性估计 + 知识迁移”的结合思路：不确定性用于判断教师知识的可靠程度，知识蒸馏用于迁移分类语义。相关理论依据主要来自知识蒸馏方法以及深度模型不确定性研究，例如 Gal 和 Ghahramani 的 MC Dropout 工作（2016）以及 Kendall 和 Gal 对视觉任务不确定性的分析（2017）。

需要注意，uncertainty-KD 是本项目基于上述思想实现的组合策略，不应表述为直接复现某一篇论文的完整方法。当前训练审计确认不确定性权重、蒸馏损失和梯度确实进入优化，但三组实验呈“两降一升”，说明机制已经生效，任务收益仍不稳定。

## 五、不确定性估计模块

### 1. 方法具体含义

不确定性估计不是简单地把“低置信度”当作未知类别，而是量化模型对预测结果的可靠程度。当前代码支持以下几类信号：

- 最大 softmax 概率的反向量：模型越不确定，最大类别概率越低；
- 预测熵：类别概率分布越分散，熵越高；
- MC Dropout 不确定性：多次随机前向预测的结果差异越大，模型越不确定；
- uncertainty head：由模型单独学习一个不确定性输出。

MC Dropout 的常见统计形式为：对同一样本进行 M 次随机前向预测，先计算平均预测分布，再计算预测熵；也可以将总预测熵与每次预测的平均熵之差作为认知不确定性近似量。

### 2. 为什么选择这些方法

最大 softmax 概率和预测熵计算简单，适合作为开放集识别的透明基线；MC Dropout 能够利用多次随机前向反映模型参数不确定性；uncertainty head 可以直接参与训练，并用于 uncertainty-KD 的样本级权重。

这些方法分别对应不同的不确定性来源，能够帮助判断收益来自单次预测置信度、随机前向差异，还是额外学习的不确定性分支。汇报时应区分：uncertainty-KD 使用的是训练中的不确定性信号；MC Dropout 主要用于不确定性分析和可选的拒识打分，不能把二者混称为同一个量。

## 六、开放集拒识与 NNPU 模块

### 1. 开放集拒识是什么

开放集识别的目标不是把所有样本强行分到已知类别，而是允许模型输出“未知”或“拒识”。常见做法是根据样本与已知类别支持区域的距离、预测置信度或能量分数，判断样本是否偏离已知分布。

这一问题的理论背景来自 Scheirer 等人提出的开放集识别与开放空间风险研究（2013），以及 Bendale 和 Boult 提出的 OpenMax 方法（2016）。本项目不直接复现 OpenMax，而是采用可校准、可比较的拒识分支和分数方法。

### 2. NNPU 是什么

NNPU 是 Non-Negative Positive-Unlabeled Learning，即非负正类—未标注学习。其基本设定是：已知类别样本可以作为有标签的一侧，候选发现池只具有未标注状态，不能简单地把池中全部样本当成未知负类。

普通 PU 风险估计在有限样本下可能出现负风险并导致训练不稳定，NNPU 通过对风险项进行非负约束，降低这种过拟合风险。该方法主要参考 Kiryo 等人的 Positive-Unlabeled Learning with Non-Negative Risk Estimator（NeurIPS 2017）。

选择 NNPU 的原因是开放环境中的候选池可能混合已知和未知样本，直接使用硬负类标签会产生错误监督。NNPU 更符合“已知样本有标签、候选池未标注”的条件。

需要区分三件事：NNPU 是拒识分支的训练目标；熵、能量、原型距离或 Mahalanobis 距离是拒识分数；阈值则只使用已知验证集进行校准。未知测试标签不能参与阈值选择。

## 七、PCA 与 KMeans 新类聚类模块

### 1. PCA 是什么

PCA 是主成分分析，通过线性变换保留特征中方差较大的方向，将高维表征压缩到较低维空间。当前将其用于候选样本聚类前的降维和去噪，而不是把 PCA 当作新类发现算法本身。

选择 PCA 的原因是它结构简单、解释性强，能够降低高维特征中的冗余，并为后续 KMeans 提供更稳定的输入。其理论基础来自主成分分析方法的经典研究。

### 2. KMeans 是什么

KMeans 通过最小化样本到所属聚类中心的平方距离，将样本划分为 K 个簇。项目中将它作为候选新类的初步组织方法，观察拒识候选是否能够形成相对清晰的类别结构。

选择 KMeans 的原因是：它实现简单、基线清晰，便于比较不同拒识表征对聚类结果的影响。当前流程中的聚类仍是两阶段候选聚类，不等同于已经完成端到端的新类发现。KMeans 的基础可追溯到 Lloyd 的最小二乘量化算法（1982）；新类发现任务的整体研究可参考 Han 等人的 DTC 方法（ICCV 2019）。

如果使用已知新类数量作为 K，应明确标注为 oracle K，只能作为分析基线；如果使用 silhouette 等方法自动估计 K，则应单独报告，不能将两种设置混为同一结果。

## 八、评价指标为什么不能只看一个

### 1. 分类指标

分类准确率或已知类别效用用于确认拒识方法没有通过大量误拒已知样本来换取表面上的未知拒识率提升。

### 2. AUROC

AUROC 衡量已知和未知样本在拒识分数排序上的整体区分能力，不依赖单一阈值。因此适合判断分数排序是否改善，但它不等价于某一个固定工作点上的实际拒识率。

### 3. 固定工作点未知拒识率

该指标在已知类别保留率或验证集校准条件固定的情况下，观察未知样本有多少被拒识。它更接近系统实际运行时的决策效果，但对阈值位置和已知样本误拒较敏感。

### 4. 聚类指标

聚类准确率、NMI 和 ARI 用于判断候选样本是否形成了与真实新类别相对应的结构。聚类指标只能在最终分析阶段使用未知标签，不能把这些标签用于训练、阈值校准或模型选择。

因此，本项目同时报告分类、AUROC、未知拒识率和聚类指标，是为了区分“分数排序变好了”“固定工作点变好了”和“完整新类发现变好了”这三种不同结论。

## 九、可以向老师概括的方法选择逻辑

本项目先用 scratch CNN 建立无蒸馏基线，再用 standard-KD 判断普通知识迁移是否有效；在此基础上引入 shared-backbone，检验共享表征能否改善未知拒识；随后引入 uncertainty-KD，利用不确定性调节教师知识的迁移强度；最后通过拒识、候选筛选、PCA 降维和 KMeans 聚类对未知样本进行初步组织。

这一顺序的优点是每一步都有明确对照：如果 shared-backbone 有改善，可以归因于共享表征；如果 uncertainty-KD 有改善，可以进一步分析不确定性加权的作用；如果拒识改善但聚类没有改善，则说明问题出现在候选覆盖或候选池质量，而不是简单归因于分类模型性能。
