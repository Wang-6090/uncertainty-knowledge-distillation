# 开题以来项目进展汇报稿

## 一、研究问题和实验协议的进一步明确

开题之后，我们首先对研究任务进行了具体化。项目研究的是开放环境下的新类发现问题：训练阶段只掌握已知类别的标注信息，测试或实际应用阶段可能出现训练阶段没有见过的新类别。因此，系统需要依次完成三个环节：已知类别分类、未知样本拒识，以及对筛选出的未知样本进行新类别聚类。

未知样本拒识是指模型判断样本是否属于已知类别，并将不属于已知类别的样本从分类结果中分离出来；新类别聚类则是在没有新类别标签的条件下，按照特征相似性对筛选出的未知样本进行分组。

为了保证实验符合开放环境设定，我们规定：未知类别标签不能参与训练、模型选择和阈值校准，只能在最终评价阶段使用。否则，模型就提前获得了未知类别信息，实验结果会被高估。这一设定参考了开放集识别中训练类别与未知类别分离的基本原则，也是后续所有对照实验的共同前提。

## 二、数据集划分和实验环境建设

在数据方面，目前主要使用 CIFAR-100，完成了 60/40 已知—未知类别划分，并增加了 semantic-hard 类别划分和三组不同类别划分。

60/40 划分的作用是建立统一、清晰的开放集实验条件：一部分类别用于训练，另一部分类别只在测试和最终评价阶段出现。semantic-hard 划分重点考察语义相近类别之间的区分问题，因为新类别如果与已知类别具有相似外观或语义，最容易被模型误判为已知类别。三组不同划分则用于检验实验结论是否只在某一次类别划分中成立。

我们同时固定了数据增强、数据标准化、训练集与验证集隔离、测试流程和评价规则。这样做的原因是，如果每个方法使用不同的数据处理方式，就无法判断性能变化究竟来自算法，还是来自实验条件差异。

## 三、分类模型和知识蒸馏程序的建立

在模型训练方面，我们建立了教师模型和学生模型的训练程序，并设置了四类对照方法。

当前主要复核配置采用 ResNet-34 教师模型和 ResNet-18 学生模型。学生模型的分类主干负责提取图像特征，并连接分类头、不确定性估计头和拒识分支：分类头输出已知类别预测，不确定性头输出独立的不确定性分数，分类概率还可以计算最大置信度和预测熵，拒识分支则学习样本是否偏离已知类别支持区域。拒识分支进一步输出拒识表征，用于候选样本筛选和后续聚类。当前 shared-backbone 主线的“共享”主要指拒识编码器复制学生分类主干的结构和参数进行初始化；初始化完成后，拒识编码器独立训练，分类主干、拒识编码器、分类头和拒识头并不持续共用同一组参数。因此，这里更准确的说法是“共享主干初始化”，而不是参数始终共享。

第一类是 scratch CNN，即不使用教师模型知识、直接利用训练数据学习分类表征的基础模型。将其作为基础对照，可以确定不使用知识蒸馏时模型的分类和开放集识别水平，为后续方法比较提供参照。

第二类是 standard-KD，即标准知识蒸馏。知识蒸馏的含义是：先训练一个性能较强的教师模型，再让学生模型学习教师模型的输出分布，而不仅仅学习“正确类别”这一项硬标签。教师模型输出的类别概率包含了不同类别之间的相似性信息，因此学生模型可以获得比硬标签更丰富的监督。

标准知识蒸馏通常使用教师模型和学生模型输出分布之间的温度缩放 KL 散度进行约束，并对一个批次中的样本采用相同的蒸馏形式。我们选择 standard-KD，是因为它是最基本、最容易复现的蒸馏方法，可以作为判断“普通知识迁移是否有效”的对照。该方法主要参考 Hinton 等人 2015 年提出的知识蒸馏方法。

第三类是 shared-backbone。它不是一种新的损失函数，而是一种表征结构：当前主线中，拒识编码器复制学生模型分类主干的结构和参数进行初始化，再作为独立编码器继续训练。也就是说，分类主干和拒识编码器在初始化时具有相同的表征基础，后续参数可以分别更新；它不是两个分支始终绑定同一组参数。

之所以研究 shared-backbone，是因为分类和未知拒识都依赖特征空间。如果分类模型和拒识模型使用完全不同的特征，分类语义与拒识边界可能不一致；共享主干可以让拒识分支利用已经学习到的类别结构。这一做法借鉴了共享表征和多任务学习的基本思想，在本项目中被改造成针对开放集拒识的对照方案。

第四类是 uncertainty-KD，即不确定性感知知识蒸馏。标准蒸馏默认教师模型对每个样本的判断都同样可靠，但教师模型遇到语义相近的新类别时，也可能产生过高置信度的错误判断。因此，我们尝试利用教师模型的不确定性调整蒸馏强度：教师越确定，学生越充分地学习该样本的知识；教师越不确定，蒸馏权重越小，避免学生直接继承教师模型可能存在的错误判断。具体实现是在逐样本 KL 蒸馏损失上乘以由教师不确定性计算出的权重，当前形式约为 (e^{-u})；因此 uncertainty-KD 与 standard-KD 的主要差别在于是否进行逐样本的不确定性加权，而不是更换教师模型或学生模型结构。

项目记录预测置信度、预测熵、不确定性头输出以及 MC Dropout 多次前向预测得到的统计量。它们不是同一个量：置信度和预测熵由分类概率分布计算，不确定性头输出独立的标量，MC Dropout 用于观察随机前向结果的稳定性。MC Dropout 的理论依据来自 Gal 和 Ghahramani 2016 年关于深度模型不确定性估计的研究。

uncertainty-KD 的具体作用不是直接判断新类别，而是调整教师知识进入学生模型的方式。教师不确定性会进入逐样本 KD 权重；预测熵或不确定性头是否进入拒识评分，则由具体拒识评分模式决定，并非所有实验设置都会自动融合。因此，它首先影响特征学习，之后再观察这种特征是否有利于未知检测和新类聚类。

## 四、未知检测和拒识模块的建立

完成分类模型后，我们进一步建立了未知样本拒识流程。开放集拒识的基本思想是：如果一个样本距离所有已知类别都较远，或者模型对它的类别判断不够确定，就不应该直接把它归入某个已知类别。

项目中对比和实现了多种拒识信号，包括最大 softmax 概率、预测熵、能量分数、原型距离和 Mahalanobis 距离等。这些方法的含义不同：最大 softmax 概率反映模型最有把握的类别；预测熵反映概率分布是否分散；原型距离衡量样本与已知类别中心的距离；Mahalanobis 距离进一步考虑已知特征分布的协方差结构。

选择这些分数的原因是它们分别从置信度、概率分布和特征空间距离三个角度判断未知样本，便于分析未知检测效果究竟来自哪一种信息。开放集识别的理论背景主要参考 Scheirer 等人 2013 年关于开放空间风险的研究，以及 Bendale 和 Boult 2016 年提出的 OpenMax 思路。本项目没有直接复制 OpenMax，而是采用更容易在现有教师—学生框架中比较和校准的分数方法。

在拒识分支的训练中，我们还使用了 NNPU 思路。NNPU 是 Non-Negative Positive-Unlabeled Learning。它适用于这样的情况：已知类别样本有标签，但候选发现池中可能同时包含已知和未知样本，不能简单地把候选池全部当成“未知正类”或“未知负类”。

如果直接把候选池全部当作负类，错误标签会导致拒识模型学习错误边界。NNPU 通过非负风险估计，避免把混合的未标注样本全部当成纯未知样本。该方法主要参考 Kiryo 等人 2017 年提出的 PU 学习方法。

具体流程是：先从学生模型的分类表征或独立拒识表征中提取拒识特征，再把有标签的已知样本作为可靠的已知侧样本，把混合发现池作为未标注样本输入 NNPU 风险估计。风险函数用未标注池估计未知侧风险，同时扣除其中可能来自已知分布的部分，并对负的正类风险进行非负截断，从而训练拒识器输出未知分数。当前主线的 shared-backbone 配置使用学生分类主干的复制初始化来建立独立拒识编码器，拒识器训练完成后再按选定评分模式使用拒识分数，必要时与分类不确定性进行融合。最终阈值仅根据已知验证集进行校准，未知测试标签不参与阈值选择。

## 五、候选筛选和新类别聚类流程

数据流顺序为：输入图像先经过学生模型得到分类 logits、预测不确定性和拒识表征；拒识器根据已知支持区域学习到的分数对样本进行排序或筛选；筛选出的候选未知样本再进入 PCA 降维和 KMeans 初步聚类。由此，分类表征和拒识评分先影响候选池，PCA 和 KMeans 只处理已经筛选出的候选特征。

PCA 是主成分分析，作用是把高维特征压缩到较低维空间，并保留变化较大的主要方向。选择 PCA 是因为它结构简单、可解释性强，可以减少高维特征中的冗余，便于后续聚类。PCA 本身不是新类发现方法，只是聚类前的特征整理步骤。

KMeans 是一种聚类方法，它通过寻找若干个聚类中心，把距离相近的样本划分到同一个簇中。我们选择 KMeans 作为初步聚类基线，是因为它实现简单、结果容易解释，适合比较不同拒识表征对候选样本结构的影响。KMeans 的基础可以追溯到 Lloyd 1982 年提出的最小二乘量化方法。

当前聚类流程属于“两阶段新类发现”：先拒识筛选候选，再进行聚类。因此，聚类效果不仅取决于 KMeans，也取决于前面的候选覆盖率和候选池污染程度。如果语义相近的新类别没有被筛选出来，后面的聚类就不可能恢复完整的新类别；如果候选池中混入过多已知样本，聚类也会受到干扰。

## 六、近期对照实验结果和方法验证

在三组类别划分的重复实验中，shared-backbone 将 AUROC 从 0.7675 提升至 0.7995，平均提高 0.0320；未知类别拒识率从 21.55% 提升至 25.16%，提高 3.61 个百分点，而且三组实验的改善方向一致。

这说明共享主干表征对未知拒识具有较稳定的局部帮助。原因可能是分类表征和拒识分支使用了相对一致的特征空间，使已知类别支持区域的结构更容易被拒识分支利用。目前的证据主要集中在未知检测环节，完整新类发现流程还需要结合候选覆盖率和聚类结果继续评价。

对于 uncertainty-KD，我们先通过训练审计检查不确定性权重、蒸馏损失和梯度是否真正进入优化。结果确认该机制确实生效。但三组实验中未知类别拒识率分别由 29.63% 降至 22.90%、由 30.55% 降至 26.80%、由 28.95% 提升至 29.48%，呈现“两降一升”。三组均值由 29.71% 变为 26.39%，由于不同类别划分下变化方向不一致，当前将 uncertainty-KD 定位为已实现、待进一步验证的消融方案，尚未纳入默认方法。

## 七、目前发现的核心问题

当前主要问题不是实验流程没有实现，而是语义相近的新类别仍可能落入已知类别的支持区域。这样会产生三步影响：首先，未知样本被误判为已知类别，造成未知漏检；其次，真正的新类别候选覆盖不足；最后，漏检和误检共同影响候选池，使聚类结果不稳定。

这也解释了为什么 AUROC、固定工作点拒识率和聚类结果不一定同步变化。AUROC 反映的是整体分数排序，固定工作点拒识率反映的是某一个阈值下的实际决策，而聚类指标还受到候选池组成的影响。因此，完整结论需要综合三个环节的指标。

## 八、下一阶段计划

下一阶段将围绕上述问题开展逐类别误差分析，统计不同新类别的漏检情况，检查候选池中的已知样本污染，并分析已知类别支持区域的边界。

同时，我们会继续比较不同表征学习方案对候选覆盖和聚类稳定性的影响，补充多划分和消融实验，并统一记录分类、AUROC、未知拒识率和聚类指标。

最终希望回答三个问题：第一，共享表征是否能够稳定改善未知拒识；第二，不确定性知识蒸馏在什么条件下能够产生收益；第三，拒识指标的改善能否真正转化为稳定的新类聚类结果。
